# 更新日志

## 1.0.0（2026-10-30）

首个开源版本。28 个真实插件长期运行验证，全套 race 测试与端到端验收通过。

### 稳定性

- OneBot 连接 30s 心跳保活，对端假活秒级检出、指数退避重连
- 插件崩溃自动重启（连续 6 次熔断）；挂死（连续 5 次超时）自动禁用
- 写管道 5s 超时判死重建

### 共享运行时宿主（cohost，默认开启）

- 多池隔离、单插件 24h 崩 3 次逐出、池级熔断、逐出状态跨重启保留
- 实测 28 插件：内存 1.0GB → ~430MB

### 可观测性与运维

- 24h 指标时间序列（消息 / 回复 / 插件延迟 / 内存 / 队列深度）
- 配置热重载、日志 8MB 轮转、插件设置备份与恢复
- `/readyz` 就绪探针、消息全链路 trace

### 安全

- ed25519 签名插件包 + 三层信任（官方 / 配置 / 热加），逐文件 sha256 校验
- 插件权限分级（read/write/admin/dangerous）、发送白名单、门禁审计
- WebUI：PBKDF2 密码、CSRF、登录限速

### 工具链

- qixinpack：new / dev（假协议端热重载）/ test / verify（端到端）/ pack / keygen / check
